
# MISSÃO 001 — GERENCIADOR DE TAREFAS

## Objetivo

Desenvolver um pequeno gerenciador de tarefas
utilizando Python.

## Funcionalidades

- Criar uma tarefa.
- Listar tarefas cadastradas.
- Marcar uma tarefa como concluída.
- Excluir uma tarefa.
- Salvar tarefas em arquivo JSON.
- Recuperar tarefas ao reiniciar o programa.

## Requisitos técnicos

- Python.
- Utilizar apenas a biblioteca padrão.
- Separar lógica de negócio da interface.
- Criar testes automatizados com unittest.
- Não utilizar banco de dados.
- Não instalar dependências externas.

## Critérios de sucesso

- Todas as funcionalidades implementadas.
- Testes automatizados aprovados.
- Dados persistidos corretamente.
- Código organizado e documentado.
- Nenhuma alteração fora do workspace da missão.
